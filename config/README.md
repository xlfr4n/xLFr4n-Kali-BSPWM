Esta carpeta contiene la configuración reproducible del escritorio Kali BSPWM: BSPWM, SXHKD, Polybar, Tint2, Rofi, Ghostty + tmux, Picom, Dunst, Zsh, Fastfetch, iconos y launchers.

## 🇺🇸 English

This directory contains the reproducible Kali BSPWM desktop configuration: BSPWM, SXHKD, Polybar, Tint2, Rofi, Ghostty + tmux, Picom, Dunst, Zsh, Fastfetch, icons and launchers.

Visual rule: **red = signal · white = information · dark = surface · no decorative red frames**.

Ghostty is the supported graphical terminal and tmux owns persistence/multiplexing. TARGET, IP and date are runtime session data.
