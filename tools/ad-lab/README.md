# 🟥 xLFr4n // Active Directory Lab Tools

## 🇪🇸 Español

Estos scripts están diseñados para las VMs AD aisladas del laboratorio.

- `Provision-DC.ps1` — prepara AD DS/DNS, dominio sintético `xlfr4n.test`, OUs y cuentas de práctica.
- `Join-Client.ps1` — incorpora un cliente con credenciales introducidas de forma interactiva.
- `Test-ADLab.ps1` — comprueba dominio, DNS, descubrimiento del DC y OUs base.

No se guardan contraseñas ni secretos en Git.

## 🇺🇸 English

These scripts are intended for the isolated AD lab VMs.

They provision the synthetic `xlfr4n.test` environment, join clients interactively and validate the base lab topology.

Credentials are not stored in Git.
