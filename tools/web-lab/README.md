# 🌐 xLFr4n // Web Lab

## 🇪🇸 Español

Objetivo web autocontenido para entrenamiento autorizado con datos sintéticos. Requiere `LAB_MODE=isolated-lab`.

~~~bash
cd tools/web-lab
chmod +x reset.sh test.sh
./reset.sh
./test.sh http://127.0.0.1:8080
~~~

Las superficies débiles están diseñadas para practicar identificación y evidencia dentro de una red aislada.

## 🇺🇸 English
