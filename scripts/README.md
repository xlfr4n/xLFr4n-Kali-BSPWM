## 🇪🇸 Español

Los helpers son la capa operativa del escritorio: autostart, target, dock, wallpaper, themes, monitors, network, audio, diagnóstico y laboratorio.

Helpers clave: `xlfr4n-terminal`, `kali-menu`, `dock`, `dock-launch`, `settarget`, `target-pulse`, `target-copy`, `cleartarget`, `theme-switch`, `wallpaper`, `doctor.sh`, `session-profile` y `lab`.

El objetivo es que cada helper haga una cosa clara, sea comprobable y no esconda efectos secundarios innecesarios.
